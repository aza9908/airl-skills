# Статическая демо-версия хаба (Netlify)

Прошлая публикация: https://airl-hub-demo.netlify.app — только экран руководителя. Новая сборка (`dist-static/`)
содержит **экран руководителя и все пять сервисов отделов** (Финансы, Продажи, Маркетинг, Обучение, HR) на снимке
**синтетических** данных под ролью `ceo`. Без входа, ролей, базы и сервера: это витрина; полная версия — `docker compose up`.

## Как собрать
На запущенном стенде (`bash scripts/setup_db.sh && bash scripts/dev_up.sh`):
```bash
python3 scripts/build_static.py              # → dist-static/ (в git не попадает)
python3 -m http.server 8099 --bind 127.0.0.1 -d dist-static &
node tests/static.playwright.js http://127.0.0.1:8099   # каждая страница и раздел, телефон 390 px, переключатель
```
Что делает `scripts/build_static.py` (только стандартная библиотека Python):
1. Входит как `ceo` (пароль — `DEMO_PASSWORD` из `.env`); cookie помечена `Secure`, поэтому отправляется заголовком `Cookie`.
2. Находит все GET-запросы страниц: вызовы `api('…')` в `services/*/public/*.js` и `services/shared/static/ui.js`,
   ряды графиков `S('…')` экрана руководителя. Переменные части раскрывает: период (день, неделя, месяц, квартал),
   месяц и юрлицо ОПиУ, коды потоков, клиенты-должники, новые сотрудники, кампании (правила — `SOURCES` в скрипте;
   новое выражение без правила останавливает сборку, чтобы страница не осталась без данных).
3. Снимает ответы в `data/*.json` (имя — путь с запросом, всё кроме латиницы и цифр → `_`). `/auth/me` — со всеми пятью
   сервисами, поэтому переключатель отделов работает.
4. Раскладывает страницы: экран руководителя в `/` (`services/hub/public` без страницы входа и service worker), каждый
   сервис — в `/<id>/` со своими `assets/`, общие файлы — в `/assets/`; в каждую страницу подключает файлы этой папки.

## Файлы этой папки
| Файл | Что делает |
|---|---|
| `static-mode.js` | подменяет `fetch`: `/auth/me`, `/hub/api/…`, `/<сервис>/api/…` → `data/*.json`; запись (POST) — ответ «Демо-версия только для просмотра»; плашка «демо, синтетические данные» |
| `static-after.js` | отключает service worker и «Выйти» (ведёт на экран руководителя) |
| `static.css` | стиль плашки |
| `sw.js` | пустой service worker: снимает кэш прошлых версий |
| `_redirects` | только `/login` → `/` |
| `_headers`, `netlify.toml` | `noindex`, без сборки на Netlify (папка публикуется как есть) |

## Публикация
Не выполнялась в этой задаче. Когда нужно: Netlify → папка `dist-static/` целиком (drag-and-drop или `netlify deploy --dir dist-static`).
