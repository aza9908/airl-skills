# SKILL_GAPS.md — что поправить в навыках по итогам демо-хаба

Файлы `skills/` в этой ветке **не правились** — только предложения. Важность: **Б** — мешает дойти до
работающего хаба / даёт неверные цифры; **В** — заметная потеря времени; **П** — шлифовка.
