# ТЗ сервиса «Обучение» — отдел Обучение (курс VibeOps)

## 1. Боль и результат
**Сейчас**: заполненность ближайших потоков считают по оплатам вручную; кто из слушателей
отстаёт — знает только куратор в чате; доля завершивших видна после окончания потока.
**Цена боли**: ~2 ч в неделю на сводку + отсев 18 % (ПРЕДПОЛОЖЕНИЕ по синтетике).
**После запуска**: заполненность потоков на 45 дней вперёд и отметки «риск отсева» в одном месте.
**Метрика успеха для Demo Day**: сводка 2 ч → 0; отсев 18 % → 12 % (итог — через поток, не к Demo Day).

## 2. Пользователи и роли
| Роль | Кто | Как часто | Что делает |
|---|---|---|---|
| `head_edu` | руководитель обучения | ежедневно | все потоки, отметки |
| `staff_edu` | куратор | ежедневно | только свои потоки (`mart_edu.edu_curators`), «Отметить риск» |
| `ceo` | руководитель | раз в неделю | потоки; имена слушателей — с маской |

## 3. Главное действие
«Отметить риск» слушателя в своём потоке — 2 касания (Потоки → поток → кнопка в строке).

## 4. Экраны
### 4.1 Обзор — записи, заполненность, доля завершивших (из `metrics`); записи по месяцам; ближайшие потоки.
### 4.2 Потоки — поток, формат, старт, мест, продано, заполнено (светофор), завершили, под риском. Пусто: «Потоков нет».
### 4.3 Поток — слушатели (имя, статус, посещаемость, проект, отметка), «Отметить риск»: уровень (риск / наблюдаем / решено), причина, что сделали. Пусто: «В потоке пока нет слушателей». Ошибка сети: «Нет сети: отметка не сохранена, попробуйте ещё раз».

## 5. Данные
### Читает
| Откуда | Что | Зачем |
|---|---|---|
| `metrics.kpi_period`, `metrics.series`, `metrics.cohort_fill_rate_detail` | записи, заполненность, завершение | обзор, потоки |
| `core.cohorts`, `core.enrollments` | потоки, слушатели, посещаемость | экраны |
| `core.clients(client_id, kind, name)` | имя слушателя (без ИИН, телефона, e-mail) | экран потока |
### Записывает (только `mart_edu`)
| Таблица | Что | Кто |
|---|---|---|
| `edu_flags` | отметки «риск отсева» (одна активная на слушателя, история — в `airl_audit`) | `head_edu`, `staff_edu` (свои потоки) |
| `edu_curators` | логин → куратор | команда AIRL |

## 6. Показатели
| id из карты | Где | Светофор |
|---|---|---|
| `enrollments`, `cohort_fill_rate`, `course_completion_rate` | Обзор | раздел 4 карты |
| `edu_at_risk` | хаб, предупреждения | 0 — ok, 1–3 — warning, > 3 — danger |

## 7. Что отдаёт в хаб
| id | Название | Период | Зелёный | Жёлтый | Красный |
|---|---|---|---|---|---|
| `enrollments` | Записи на курс | месяц с 1-го по вчера | ≥ −10 % | −10…−25 % | < −25 % |
| `cohort_fill_rate` | Заполненность потоков | потоки 45 дней вперёд | > 85 % | 70–85 % | ≤ 70 % |
| `course_completion_rate` | Доля завершивших | потоки за 90 дней | > 80 % | 65–80 % | ≤ 65 % |
| `edu_at_risk` | Слушатели под риском | сейчас | 0 | 1–3 | > 3 |
Предупреждения: поток стартует в течение 3 недель и заполнен < 70 %; слушатели под риском.
