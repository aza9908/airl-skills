# ТЗ сервиса «HR» — отдел HR

Автор: Claude (роль инженера AIRL), по шаблону `skills/airl-spec/templates/SPEC.hub.md`

## 1. Боль и результат
**Сейчас**: вакансии ведутся в Google Таблице и висят месяцами; онбординг новичка — в чатах, кто что не сделал,
выясняется через месяц; ФОТ по отделам и текучесть руководитель узнаёт у бухгалтерии раз в квартал.
**Цена боли**: ~3 ч в неделю HR на сводки и напоминания; средний срок найма 40–50 дней; 30–40 % пунктов
адаптации закрываются с опозданием (ПРЕДПОЛОЖЕНИЕ по синтетике).
**После запуска**: численность, текучесть, вакансии, ФОТ по отделам — в хабе каждый день; онбординг — чек-листом
с просрочками и кнопкой «Готово».
**Метрика успеха для Demo Day**: сводки 3 ч → 0; онбординг в срок 70 % → 85 % (итог — через 2 месяца пилота).

## 2. Пользователи и роли
| Роль из карты | Кто это | Как часто | Что делает |
|---|---|---|---|
| `head_hr` | руководитель HR | ежедневно | всё: обзор, вакансии, онбординг всех отделов, ФОТ по отделам |
| `staff_hr` | HR-менеджер | ежедневно | онбординг своих отделов (`mart_hr.hr_staff_scope`), «Готово» по пункту; вакансии; **без ФОТ** |
| `ceo` | руководитель | раз в неделю | всё, кроме имён: имена новичков — с маской; менять ничего не может |

## 3. Главное действие
«Готово» по пункту онбординга новичка — 3 касания (Новые сотрудники → сотрудник → «Готово»).

## 4. Экраны
### 4.1 Обзор
Зачем: кадры одним взглядом · сверху вниз: карточки численность, текучесть, срок найма, открытые вакансии, ФОТ
(те же дни прошлого месяца), онбординг в срок; «Найм и увольнения» по месяцам; ФОТ по отделам (кольцо, только
`ceo`/`head_hr`, у `staff_hr` — численность по месяцам) · загрузка: скелет · ошибка: «Не удалось загрузить данные: …».
### 4.2 Вакансии
Открытые (дни открыта: > 35 — жёлтая, > 50 — красная, источник, отклики) и закрытые за 180 дней. Пусто: «Вакансий нет».
### 4.3 Новые сотрудники
Онбординг в срок по месяцам; таблица «сотрудник (Фамилия И.), должность, отдел, пришёл, день, сделано, просрочено».
Пусто: «Новых сотрудников за последние 120 дней нет».
### 4.4 Сотрудник (онбординг)
Чек-лист: пункт, вид, кто отвечает, срок, статус (в срок / с опозданием / просрочен N дн.), кнопка «Готово»
(HR) с комментарием. Нет сети: «Нет сети: отметка не сохранена, нажмите ещё раз».
### 4.5 ФОТ и отсутствия (`ceo`, `head_hr`)
ФОТ по месяцам; ФОТ по отделам за прошлый месяц (малые отделы объединены); дни отпусков и больничных по отделам за 3 месяца.

## 9. Доступы и персональные данные
ПДн в сервисе: ФИО сотрудников (на экранах — «Фамилия И.»). Особые данные: больничные — только днями по отделу,
по человеку в хаб не попадают. Без маски видят: `head_hr`, `staff_hr` (свои отделы). Маска: `ceo` — «Ш*** М***».
Оклады людей не видит никто: их нет ни в `core`, ни в витрине; ФОТ — суммой по отделу, отделы до 3 человек
объединены. Открытых адресов нет. Сервис людям не пишет. Языки: ru.
