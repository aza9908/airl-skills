# ТЗ сервиса «Маркетинг» — отдел Маркетинг

Автор: Claude (роль инженера AIRL), по шаблону `skills/airl-spec/templates/SPEC.hub.md`

## 1. Боль и результат
**Сейчас**: расход смотрят в трёх кабинетах (Meta, Google, Telegram) и в таблице бюджета, заявки — в amoCRM, оплаты —
в 1С; цена заявки и окупаемость канала считаются вручную раз в месяц, перерасход бюджета видно после закрытия месяца.
**Цена боли**: ~4 ч в неделю на сводку; последние 2 месяца расход вырос на 40 % при росте цены заявки на 25 %
(синтетика) — заметили бы только по итогам квартала.
**После запуска**: расход, CPL, CAC, ROMI по каналам и кампаниям каждый день; прогноз бюджета месяца со светофором.
**Метрика успеха для Demo Day**: сводка 4 ч → 0; перерасход бюджета виден на 3-й день месяца, а не после закрытия.

| `staff_marketing` | маркетолог (SMM) | ежедневно | вся аналитика; заметки — только к кампаниям своих каналов (`mkt_staff_channels`) |

## 3. Главное действие
«Изменить бюджет» канала на месяц — 3 касания (Бюджет → строка канала → «Сохранить» с причиной).

## 4. Экраны
### 4.1 Обзор
Карточки: расход, CPL, CAC, ROMI, конверсия заявок на курс, заявки (те же дни прошлого месяца); расход по каналам
(кольцо) и по месяцам; CPL и ROMI по каналам (полосы фиолетовый → розовый); таблица каналов. Пусто: «Расхода за период нет».
### 4.2 Кампании
Кампании месяца: расход, заявки («0 · проверьте UTM» — расход без заявок), CPL, слушатели, ROMI; «Заметка».
### 4.3 Бюджет
Текущий месяц: бюджет, факт, прогноз по темпу, прогноз к бюджету (110 % — жёлтый, 125 % — красный); следующий месяц — план.
Кнопка «Изменить бюджет» (руководитель). Ошибка: текст сервера («Напишите, почему меняете бюджет»).

## 7. Что отдаёт в хаб
| id | Название на плитке | Период | Зелёный | Жёлтый | Красный |
|---|---|---|---|---|---|
| `ad_spend` | Расход на рекламу | месяц с 1-го по вчера | рост < 20 % | 20–40 % | ≥ 40 % |
| `cpl` | Цена заявки (CPL) | то же | рост < 10 % | 10–25 % | ≥ 25 % |
| `cac` | Цена слушателя (CAC) | то же | рост < 10 % | 10–25 % | ≥ 25 % |
| `romi` | Окупаемость рекламы (ROMI) | то же | > 200 % | 100–200 % | ≤ 100 % |
Предупреждения: прогноз расхода > 110 % бюджета; канал с ростом CPL > 25 %; кампании с расходом без заявок.
