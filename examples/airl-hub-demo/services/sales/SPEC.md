# ТЗ сервиса «Продажи» — отдел Продажи

## 1. Боль и результат
**Сейчас**: заявки живут в amoCRM, оплаты — в 1С; конверсию и выполнение плана считают в конце
месяца в Excel; менеджеры забывают перезвонить по зависшим заявкам.
**Цена боли**: ~3 ч в неделю на отчёт + зависшие заявки (ПРЕДПОЛОЖЕНИЕ: 140 открытых заявок старше 3 дней).
**После запуска**: воронка по каналам и прогноз выполнения плана каждое утро; напоминания «перезвонить».
**Метрика успеха для Demo Day**: отчёт 3 ч/нед → 0; заявки старше 3 дней без напоминания 140 → < 20.

## 2. Пользователи и роли
| Роль | Кто | Как часто | Что делает |
|---|---|---|---|
| `head_sales` | руководитель продаж | ежедневно | воронка, план-факт, меняет план |
| `staff_sales` | менеджер | ежедневно | свои открытые заявки, «Перезвонить» |
| `ceo` | руководитель | раз в неделю | смотрит воронку и план |

## 3. Главное действие
Менеджер — «Перезвонить» по своей заявке (экран открывается сразу на «Мои заявки», 2 касания);
руководитель — «Изменить план» (новая версия, старая остаётся в истории).

## 4. Экраны
### 4.1 Воронка — заявки, конверсия, средний чек (из `metrics`), выполнение плана (модуль), заявки по месяцам, каналы месяца. Пусто: «Заявок пока нет».
### 4.2 План-факт (модуль plan-fact) — план, факт, прогноз, % по прогнозу со светофором; «Изменить план» (только `head_sales`; причина обязательна). Пусто: «Планов на этот месяц нет».
### 4.3 Открытые заявки — `staff_sales` видит только свои (по `mart_sales.sales_staff`), руководитель — все; «Перезвонить» (дата, комментарий). Контакты клиента в хаб не загружаются — звонить из amoCRM. Пусто: «Открытых заявок нет».

## 6. Показатели
| id из карты | Где | Светофор |
|---|---|---|

## 7. Что отдаёт в хаб
| id | Название | Период | Зелёный | Жёлтый | Красный |
|---|---|---|---|---|---|
| `lead` | Заявки | месяц с 1-го по вчера | ≥ −10 % к тем же дням | −10…−25 % | < −25 % |
| `conversion_lead_to_deal` | Конверсия | то же | > 8 % | 5–8 % | ≤ 5 % |
| `avg_check` | Средний чек | то же | ≥ −10 % | −10…−25 % | < −25 % |
| `plan_completion:revenue` | Выполнение плана · выручка | текущий месяц | ≥ 95 % (прогноз) | 85–95 % | < 85 % |
Предупреждения: открытые заявки старше 3 дней без напоминания; красные строки плана.
