# Если …, то …

Частые ситуации курса для всех ролей. В каждой строке: что делать, кто делает
и где подробности (навык или инструкция). Слова — в [glossary.md](glossary.md).

Роли: **У** — участник, **Т** — тренер, **И** — инженер AIRL,
**PM** — продакт-менеджер, **Р** — руководитель клиента.

## Установка и первые шаги

| № | Если … | то … | Кто | Где подробнее |
|---|---|---|---|---|
| 1 | Windows не ставит git (нет прав администратора) | попросить ИТ-отдел поставить Git for Windows; до этого Claude Code на Windows не запустится | У → ИТ клиента | [00-novice.md](00-novice.md), шаг 2 |
| 2 | Терминал пишет `git` «не является командой» после установки | закрыть и снова открыть VS Code; не помогло — переустановить git с настройками по умолчанию | У | [00-novice.md](00-novice.md), шаг 2 |
| 3 | `command not found: claude` | поставить плагин из панели Claude: `/plugins` → Marketplaces → `aza9908/airl-skills` → Plugins → `airl` | У | [README](../README.md#установка) |
| 4 | Набрал `/airl` — список пустой | перезагрузить окно (**Developer: Reload Window**); проверить `claude plugin list` — должна быть строка `airl@airl-skills` `enabled` | У | [README](../README.md#если-что-то-не-работает) |
| 5 | Каждый навык в списке дважды | навыки стоят двумя способами; удалить один: `rm -rf ~/.claude/skills/airl-*` или `claude plugin uninstall airl@airl-skills` | У | [README](../README.md#удаление) |
| 6 | macOS спрашивает «открыть программу из интернета?» | нажать **Открыть**; если блокирует — Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть** | У | [00-novice.md](00-novice.md), шаг 3 |
| 7 | Корпоративный ноутбук блокирует установку или сайт GitHub | ИТ клиента разрешает VS Code, git, `github.com`, `claude.ai`; временно — личный ноутбук без рабочих данных | У → PM | [04-product-manager.md](04-product-manager.md), раздел 3 |
| 8 | Commit пишет «configure user.name and user.email» | `git config --global user.name "Имя"` и `git config --global user.email "почта"` | У | [00-novice.md](00-novice.md), шаг 5 |
| 9 | Claude отвечает по-английски | написать «Отвечай на русском языке» | У | — |
| 9а | Команда из инструкции не работает в PowerShell (`VAR=... python3 …`, `python3` не найден) | на Windows другие записи: `python3` → `py`, переменные задаются иначе; таблица «Windows и Mac» в `/airl-context` | У | `skills/airl-context/SKILL.md` |
| 9б | `bash scripts/review_checks.sh` не запускается на Windows | запустить в Git Bash (ставится вместе с git) или оставить проверку CI | У | `/airl-code-review` |
