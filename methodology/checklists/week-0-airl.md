# Неделя 0 — команда AIRL

Начинается за 2–3 недели до офлайн-дня. План по дням —
[03-engineer.md](../03-engineer.md). Без пунктов, отмеченных «стоп», путь
«хаб компании» не начинается.

## PM (Алмас)

- [ ] Договор подписан, ответственные у клиента названы (1С, CRM, ИТ, юрист)
- [ ] `SCOPE.md` подписан руководителем клиента (`/airl-spec`, режим A0) — **стоп**
- [ ] Часы программиста 1С согласованы
- [ ] Администратор готовой системы назначен (если есть корзина «купить»)
- [ ] Участники: по 2–4 на отдел, у каждого 4–6 часов в неделю
- [ ] ИТ клиента разрешил установку VS Code, git и доступ к GitHub
- [ ] Блокеры описи интеграций сняты или перенесены в фазу 1

## Инженеры

- [ ] Доступ к 1С (главной учётной системе) на чтение — **стоп, если нет к концу недели**
- [ ] Организация GitHub на юрлицо клиента, шаблон репозитория сервиса собирается в CI
- [ ] Сервер в стране из профиля страны, на аккаунте клиента (`/airl-devops`, части 0–3)
- [ ] Прокси, домен хаба, сертификат (часть 4)
- [ ] Копии и проверка восстановления (часть 5)
- [ ] `raw_1c` с историей 13+ месяцев; повторная загрузка без дублей (`/airl-dwh`)
- [ ] `core`, `metrics` по карте; сверка каждого показателя за закрытый период
- [ ] Пользователи базы `svc_<отдел>`, загрузка, хаб (только чтение)
- [ ] Обезличенная копия; проверка по каждой колонке `pii` записана в `DWH.md`
- [ ] Доступ к тестовому хранилищу проверен на корпоративном ноутбуке без прав администратора
- [ ] Карта: раздел 8 «Среда для разработки» заполнен
- [ ] Провайдер входа, роли, тестовые пользователи (`/airl-hub создать хаб`, части 1–2)
- [ ] Карта: раздел 8 «Контракт входа» заполнен
- [ ] `COMPANY_MAP.md` v1.0 утверждена руководителем и финансами (`/airl-spec`, режим A)
- [ ] Репозитории отделов из шаблона, приглашения отправлены, `deploy_<id>` и ключи
- [ ] `INTEGRATIONS.md`: опись заполнена (`/airl-integrations`)
- [ ] Репетиция офлайн-дня на чистом ноутбуке

## Тренер

- [ ] `/airl-progress настроить когорту`: `roster.csv`, `weights.yml` с датой старта, токен только на чтение
- [ ] Участники предупреждены о проверке прогресса
- [ ] Чат группы, расписание созвонов и офис-часов
