# Неделя 3 · Защита

Совпадает с этапом «Защита» в `/airl-progress`. В скобках — id пункта.

## Перед стартом

- [ ] Хаб: в карте заполнен «Контракт входа», есть тестовые пользователи на каждую роль

## Проверка

- [ ] `/airl-cybersecurity` пройден → `SECURITY.md` (`security_md`)
- [ ] Вход: свой продукт — готовый провайдер; хаб — только через хаб
- [ ] Роли проверяются на сервере, проверено атаками (чужой id, чужая роль)
- [ ] Хаб: запись в чужую витрину падает с ошибкой прав
- [ ] Ключи только в `.env`, `.env.example` есть, `.env` в `.gitignore`
- [ ] Персональные данные замаскированы, в логи не уходят
- [ ] Ручные задачи из «Что нужно сделать вам» выполнены
- [ ] Повторный запуск, если были «СРОЧНО»
- [ ] Вердикт в верхнем разделе: «Можно открывать людям…: да» (`security_ok`)

## Если эффект виден через дни

- [ ] Закрытый пилот на 1–2 сотрудниках начат не позже середины недели 3

## Приёмка (тренер)

- [ ] Таблица «Проверки действием» заполнена, «СРОЧНО» нет
- [ ] Пункты «Для команды AIRL» переданы инженеру
