# Словарь терминов

Слова, которые встречаются в навыках и инструкциях курса. Каждое — простыми
словами и с бытовой аналогией. Термины сгруппированы по темам.

## Работа с проектом

| Термин | Что это | Аналогия |
|---|---|---|
| **Репозиторий** | папка проекта вместе со всей историей изменений; лежит на компьютере и на GitHub | папка с документами, где хранится каждая прошлая версия |
| **GitHub** | сайт, где хранятся репозитории и где команда видит работу друг друга | облачный диск для проектов |
| **Git** | программа, которая сохраняет снимки проекта и умеет к ним вернуться | «история версий» в Google Документах |
| **Коммит (commit)** | сохранённый снимок проекта с подписью «что изменил» | кнопка «сохранить версию» с комментарием |
| **Push** | отправка коммитов на GitHub | синхронизация с облаком |
| **Pull** | получение свежих изменений с GitHub к себе | скачать новую версию общего файла |
| **Клонировать (clone)** | скачать репозиторий с GitHub на свой компьютер в первый раз | скачать общую папку себе |
| **Ветка (branch)** | отдельная копия проекта для одной задачи; основная ветка — та, что работает у людей | черновик рядом с чистовиком |
| **Основная ветка (main)** | главная версия проекта; в курсе именно она выкладывается на сервер | чистовик |
| **Pull request (PR)** | запрос «влейте мою ветку в основную», с обсуждением и проверками | заявка на согласование изменений |
| **Слияние (merge)** | перенос изменений из ветки в основную | перенос правок из черновика в чистовик |
| **.gitignore** | список файлов, которые git не сохраняет и не отправляет | список «не класть в общий шкаф» |
| **Терминал** | окно для текстовых команд компьютеру | пульт с кнопками-словами |
| **VS Code** | программа-редактор, где открыт проект, панель Claude и терминал | рабочий стол |
| **Расширение** | дополнение к программе | насадка для дрели |
| **Плагин** | пакет навыков, который ставится одной командой | набор инструментов в одном чемодане |
| **Навык (skill)** | подробная инструкция для Claude, которая ведёт по шагу курса вопросами | опытный наставник с чек-листом |
| **CLAUDE.md** | короткая памятка о проекте, которую Claude читает в начале каждого чата | записка сменщику |
| **Контекст** | всё, что Claude держит в голове в текущем чате | рабочий стол: чем больше бумаг, тем дольше искать |
| **Токен (в ИИ)** | кусочек текста, которым измеряется работа модели и лимит | счётчик слов в тарифе связи |
| **Лимит** | сколько работы Claude доступно за период | пакет минут у мобильного оператора |
| **Субагент** | помощник Claude, которому отдают поиск, чтобы не засорять основной чат | стажёр, которого посылают в архив |

## Документы курса

| Термин | Что это | Аналогия |
|---|---|---|
| **ТЗ** | техническое задание: что строим, для кого и зачем | заказ-наряд на ремонт |
| **PRD** | подробное описание продукта (Product Requirements Document): боль, пользователи, требования, критерии | паспорт продукта |
| **SPEC.md** | ТЗ продукта или сервиса отдела в репозитории | заказ-наряд, приколотый к рабочему месту |
| **ARCHITECTURE.md** | схема продукта: из каких частей, на каких технологиях, сколько стоит | план дома с коммуникациями |
| **SCOPE.md** | объём курса: какие требования клиента делаем в курсе, какие после, с подписью | смета, подписанная заказчиком |
| **COMPANY_MAP.md (карта компании)** | одна на всю компанию: системы, отделы, единые показатели, роли, правила хаба | устав компании для цифр |
| **airl.service.json** | паспорт сервиса отдела для хаба: id, роли, что читает и пишет, адреса | техпаспорт прибора |
| **Бэклог** | список задач для разработки по приоритету | очередь заказов |
| **Критерий готовности** | проверяемое условие «сделано» — действием или числом | «кран не капает 24 часа» |
| **Цена боли** | сколько стоит проблема сейчас: часы, деньги, ошибки | счёт за протекающий кран |
| **Было → стало** | цифра до и после продукта для Demo Day | фото «до и после» ремонта |

## Методы работы с продуктом

| Термин | Что это | Аналогия |
|---|---|---|
| **JTBD (Jobs to be Done)** | взгляд на продукт через «работу», которую человек хочет сделать | человеку нужна не дрель, а дырка в стене |
| **Job story** | короткая запись: «когда …, я хочу …, чтобы …» | записка-просьба коллеге |
| **User story** | задача с точки зрения пользователя: «как бухгалтер, я хочу…» | заявка от конкретного человека |
| **Эпик** | большая группа связанных задач | глава в книге |
| **MoSCoW** | сортировка требований: Must (обязательно), Should (желательно), Could (можно), Won't (не сейчас) | список покупок: хлеб — обязательно, торт — если останутся деньги |
| **RICE** | оценка приоритета: охват × влияние × уверенность / усилия | выбор, какой ремонт делать первым по пользе и цене |
| **CJM (карта пути клиента)** | шаги человека от проблемы до результата, с болями на каждом | маршрут покупателя по магазину |
| **MVP** | минимальная рабочая версия, которая уже убирает боль | первая партия пирожков на пробу |
| **Edge case** | редкий, пограничный случай, который ломает простую логику | клиент с двумя одинаковыми телефонами |
| **Пилот** | проверка продукта на 1–2 сотрудниках до запуска для всех | пробная смена |

## Данные

| Термин | Что это | Аналогия |
|---|---|---|
| **База данных** | место, где продукт хранит записи в таблицах | картотека |
| **Таблица** | набор записей одного вида: клиенты, заявки | ящик картотеки |
| **Хранилище (DWH)** | одна общая база, куда сходятся данные из 1С, CRM и таблиц | общий склад компании |
| **Сырой слой (raw)** | данные как пришли из источника, без обработки | склад приёмки |
| **core** | очищенные общие данные: клиенты, справочники, одна карточка клиента | склад, разложенный по полкам |
| **metrics** | единые показатели, посчитанные строго по карте компании | весы, поверенные для всех |
| **Витрина (mart)** | таблицы одного отдела; пишет туда только сервис этого отдела | полка с товарами одного отдела |
| **Показатель (метрика)** | число, по которому судят о работе: выручка, просрочка, конверсия | спидометр |
| **Карточка клиента** | одна запись о клиенте, собранная из всех систем | одна медицинская карта вместо пяти |
| **Справочник** | список значений, на который ссылаются записи: города, товары | телефонная книга |
| **Миграция** | пошаговое изменение таблиц базы, записанное в файл | ремонт по плану, без сноса дома |
| **Схема базы** | описание таблиц и связей между ними | план комнат |
| **Обезличенная копия** | копия данных, где ФИО, телефоны, ИИН заменены, а суммы и даты настоящие | учебный муляж с настоящими размерами |
| **Персональные данные (ПДн)** | сведения о человеке: ФИО, телефон, ИИН, адрес, здоровье | содержимое паспорта |
| **Особые данные** | здоровье, биометрия, данные о детях — защищаются строже | медицинская карта |
| **PostgreSQL** | бесплатная надёжная база данных, на которой проверены модули | проверенный сейф известной марки |
| **NoSQL** | базы без жёстких таблиц, для особых случаев | коробки вместо картотеки |
| **SQL** | язык запросов к базе | язык заявок на складе |
| **Индекс** | ускоритель поиска в таблице | алфавитный указатель в книге |
| **Адаптер src_** | представление, через которое модуль читает данные компании, не зная их источника | переходник для розетки |
| **Резервная копия (бэкап)** | снимок базы, из которого можно всё восстановить | запасной ключ у соседа |
| **PITR** | восстановление базы на любую минуту в прошлом | перемотка видеозаписи |
| **RPO / RTO** | сколько данных можно потерять / за сколько времени восстановиться | сколько страниц черновика не жалко / как быстро переписать |

| Термин | Что это | Аналогия |
|---|---|---|
| **Сервер (VPS)** | компьютер в дата-центре, где продукт работает круглосуточно | арендованное помещение под магазин |

| **Откат** | возврат к прошлой версии одной командой, если новая сломалась | вернуть старый товар на полку |
| **Docker** | упаковка продукта со всем нужным в один контейнер | контейнер на корабле: внутри всё своё |
| **Контейнер** | запущенный упакованный продукт | работающий ларёк из типового контейнера |
| **Образ (image)** | готовая упаковка, из которой запускаются контейнеры | чертёж типового ларька |
| **Docker Compose** | файл, который запускает несколько контейнеров вместе | план ярмарки: где какой ларёк |
| **Caddy (прокси)** | программа на входе сервера: принимает запросы и отдаёт нужному сервису, ставит сертификат | администратор на ресепшене |
| **Порт** | номер «двери» на сервере, через которую идёт связь | номер подъезда |
| **Межсетевой экран (firewall)** | запирает все порты, кроме нужных | охрана, которая пускает только в открытые двери |
| **SSH** | защищённый вход на сервер по ключу | ключ от служебного входа |
| **CI/CD** | автоматические проверки и выкладка после каждого изменения в GitHub | конвейер с ОТК на выходе |
| **GitHub Actions** | сервис GitHub, который запускает CI/CD | робот на конвейере |
| **Staging** | тестовая копия продукта на сервере перед боевой | примерочная |
| **Продакшен (боевая среда)** | версия, которой пользуются люди | торговый зал |
| **healthz** | служебный адрес `/healthz`: отвечает «я жив» и номер версии | пульс пациента |
| **Мониторинг** | постоянная проверка, что продукт жив, с оповещением | датчик дыма |
| **Ранбук** | готовая пошаговая инструкция на случай сбоя | памятка «что делать при пожаре» |
| **Логи** | журнал событий программы | бортовой журнал |
| **Переменная окружения** | настройка, которая задаётся снаружи кода, например адрес базы | настройки на пульте, а не в схеме прибора |
| **.env** | файл с ключами и настройками; в GitHub не отправляется | сейф с ключами |
| **.env.example** | образец `.env` без значений: какие ключи нужны | список ключей без самих ключей |

## Безопасность и вход

| Термин | Что это | Аналогия |
|---|---|---|
| **Роль** | набор прав: кто что видит и может менять | пропуск с доступом на этажи |
| **Аутентификация (вход)** | проверка «кто вы» | показать пропуск на входе |
| **Авторизация** | проверка «что вам можно» | турникет пускает только на ваш этаж |
| **Провайдер входа** | отдельный сервис, который проверяет логин и выдаёт токен; в хабе один на все сервисы | бюро пропусков |
| **Токен (в безопасности)** | длинная строка-пропуск для программы или сессии | одноразовый пропуск |
| **JWT** | токен с подписью, внутри — кто вы, роль и отдел | пропуск с печатью и фото |
| **Cookie** | маленький файл в браузере; в хабе в нём хранится вход `airl_session` | номерок из гардероба |
| **API-ключ** | секретный пароль, по которому программа обращается к другой системе | ключ от служебной двери |
| **Секрет** | любой пароль, ключ или токен; хранится только в `.env` или секретах GitHub | содержимое сейфа |
| **Двухфакторный вход** | вход по паролю и коду с телефона | замок плюс сигнализация |
| **IDOR** | атака: подставить чужой номер записи в адрес и увидеть чужое | открыть чужую ячейку, угадав номер |
| **Уязвимость** | слабое место, через которое можно навредить | незапертое окно |
| **gitleaks** | проверка, не попал ли ключ в репозиторий | металлоискатель на выходе |
| **Маскирование** | показ данных частично: `+7 701 *** ** 12` | закрытый конверт с окошком |

## Интеграции

| Термин | Что это | Аналогия |
|---|---|---|
| **API** | способ, которым программы обмениваются данными | окно выдачи в столовой |
| **Интеграция** | постоянная связь продукта с внешней системой: 1С, банк, маркетплейс | договор о поставках между двумя складами |
| **Вебхук** | сообщение, которое другая система сама присылает, когда что-то случилось | звонок курьера «я у двери» |
| **OData** | стандартный способ читать данные из 1С по сети | окно выдачи, которое 1С открывает сама |
| **Идемпотентность** | повтор того же действия не создаёт дубль | второй платёж по тому же счёту не пройдёт |
| **Outbox** | журнал исходящих записей: сначала записать «что отправить», потом отправлять с повторами | исходящая почта с отметками «отправлено» |
| **Inbox** | журнал входящих вебхуков с защитой от дублей | журнал входящей корреспонденции |
| **Dead letter** | записи, которые не удалось отправить; их разбирает человек | письма «адресат не найден» |
| **Сверка** | ежедневное сравнение «что отправили ↔ что есть в системе» | сверка кассы в конце дня |
| **Песочница** | тестовая версия внешней системы, где ошибки ничего не стоят | тренажёр вместо настоящего самолёта |
| **Водяной знак** | отметка «до какого места уже прочитали», чтобы не терять и не дублировать | закладка в книге |
| **Лимит запросов** | сколько обращений в минуту разрешает внешняя система | очередь в окно выдачи |
| **Теневой режим** | интеграция работает, но реально не отправляет — только записывает, что отправила бы | стажёр работает рядом с мастером, не трогая клиента |
