# Навыки AIRL

Навыки для Claude в VS Code. Каждый навык **сам задаёт вопросы** — по одному,
с готовыми вариантами ответа и рекомендацией. Отвечать можно одной буквой.
Технических знаний не требуется.

Два набора:

- **VibeOps** (`/airl-*`) — команды отделов строят боевые сервисы на данных компании
  (1С, Bitrix24, amoCRM, таблицы), а навыки собирают их в единый хаб руководителя.
- **Первый продукт** (`/design`, `/architecture`, `/security`) — путь от идеи
  до работающего продукта для одного человека или команды.

---

## VibeOps: сервисы отделов в одном хабе

```text
              COMPANY_MAP.md  ← /airl-spec (карта компании, одна на всех)
                    │
   ┌────────────────┼──────────────────────────────┐
   хранилище      ТЗ сервиса каждого отдела = ветка карты
   /airl-dwh      SPEC.md + airl.service.json
                    │
     /airl-pwa → /airl-cybersecurity → /airl-vps · /airl-launch · /airl-code-review-2.0
                    │
                 /airl-hub — проверяет сервис по контракту и подключает к хабу
```

| Неделя | Навык | Что делает | Что остаётся в репозитории |
|---|---|---|---|
| 1 · План | **`/airl-spec`** | Карта компании: системы, единые показатели, одна карточка клиента, роли, правила хаба. ТЗ сервиса отдела как ветка карты — начиная с боли отдела и её цены в цифрах. Апгрейдит: переводит проекты после `/design` и `/architecture` на карту и обновляет ТЗ, когда карта меняется | `COMPANY_MAP.md`, `SPEC.md`, `airl.service.json` |
| 2 · Данные | `/airl-dwh` | Подключает сервис к хранилищу, витрине отдела и единым показателям | — |
| 2 · Данные | **`/airl-pwa`** | Собирает сервис как PWA в дизайне хаба: с телефона, офлайн, установка на экран, контракт `/healthz` и `/api/hub/summary` | код сервиса |
| 3 · Защита | **`/airl-cybersecurity`** | Вход только через хаб, роли по отделам, запись только в свою витрину (права в базе), ключи в одном месте, ПДн по закону РК. Проверяет атаками | `SECURITY.md` |
| 4 · Запуск | `/airl-vps`, `/airl-launch`, `/airl-code-review-2.0` | Сервер и домен, выкладка из GitHub без остановки хаба, код-ревью | — |
| 4 · Запуск | **`/airl-hub`** | Создаёт хаб (один раз), принимает сервис по 13 воротам и подключает его, показывает готовность отделов к Demo Day | `HUB_CHECK.md`, `hub/services.json` |

Жирным — навыки из этого репозитория.

### Как пройти курс одному отделу

```
/airl-spec карта            ← один раз на компанию, в репозитории хаба
/airl-spec ТЗ отдела продаж ← в репозитории сервиса отдела, неделя 1
/airl-dwh                   ← неделя 2
/airl-pwa                   ← неделя 2
/airl-cybersecurity         ← неделя 3
/airl-hub подключить sales  ← неделя 4, после выкладки и код-ревью
/airl-hub готовность        ← перед Demo Day
```

Уже есть продукт после `/design` и `/architecture`? Запустите в его папке
`/airl-spec апгрейд` — навык сохранит экраны и технологии и покажет, что поменять,
чтобы продукт стал сервисом хаба.

### Контракт сервиса

Хаб читает из репозитория сервиса файл `airl.service.json` и опрашивает два адреса:
`{base_path}/healthz` и `{base_path}/api/hub/summary`. Проверить сервис до подключения:

```bash
python3 ~/.claude/skills/airl-hub/scripts/check_service.py --service airl.service.json --map airl/COMPANY_MAP.md --url https://hub.company.kz
```

## Первый продукт

| Навык | Что делает | Сколько занимает |
|---|---|---|
| **`/design`** | Спрашивает, что за продукт, для кого и как выглядит. Собирает карту экранов, цвета, шрифты, тексты кнопок | 10 минут |
| **`/architecture`** | Спрашивает про пользователей, данные и бюджет. Выбирает технологии с ценой и собирает работающую версию | 30–60 минут |
| **`/security`** | Спрашивает про данные и доступы. Проверяет продукт и отвечает, можно ли показывать людям | 15 минут |

## Установка

Нужно один раз. После этого навыки работают во всех ваших проектах.

### Шаг 1. Расширение Claude в VS Code

Откройте VS Code. Слева на панели найдите значок с квадратиками — это Extensions.
Или нажмите **Cmd + Shift + X** (на Windows **Ctrl + Shift + X**).

В поиске наберите **Claude Code**. Установите расширение от издателя **Anthropic**.

Справа появится значок Claude. Нажмите на него и войдите в свой аккаунт.

### Шаг 2. Откройте терминал

В меню VS Code: **Terminal → New Terminal**. Внизу появится чёрное окно.

### Шаг 3. Скопируйте одну команду

```bash
cd ~/Downloads && git clone https://github.com/aza9908/airl-skills.git && cd airl-skills && bash install.sh
```

Вставьте её в терминал и нажмите Enter. Должно появиться:

```
Готово. Установлены навыки: airl-cybersecurity airl-hub airl-pwa airl-spec architecture design security
```

### Шаг 4. Перезагрузите окно

Нажмите **Cmd + Shift + P** (на Windows **Ctrl + Shift + P**), наберите
`Developer: Reload Window`, нажмите Enter. Окно моргнёт.

Без этого шага навыки не появятся.

### Шаг 5. Проверьте

Откройте панель Claude справа и наберите в поле ввода:

```
/design
```

Или `/airl-spec`. Под полем должна появиться подсказка с описанием навыка на русском. Значит, всё готово.

## Как пользоваться

Создайте пустую папку для проекта и откройте её в VS Code:
**File → Open Folder**.

Затем в панели Claude по очереди:

```
/design «сайт для записи в барбершоп»
```

Ответьте на вопросы. Получится документ `DESIGN.md`.

```
/architecture
```

Ответьте на вопросы, утвердите технологии и цену. Продукт соберётся по частям,
после каждой вы посмотрите результат.

```
/security
```

Ответьте на вопросы. Получите отчёт и прямой ответ, можно ли показывать людям.

**Порядок важен.** Каждый навык читает то, что сделал предыдущий.

## Что появится в папке проекта

```text
DESIGN.md          как выглядит продукт: экраны, цвета, тексты кнопок
ARCHITECTURE.md    на чём собран, сколько стоит в месяц, план сборки
SECURITY.md        что проверили, что исправили, что сделать вам
```

Плюс сам код продукта.

Все три документа — обычные текстовые файлы. Откройте и читайте: в этом и смысл.
Договорённости видны глазами, а не спрятаны в переписке.

## Если что-то не работает

**Навыки не появились после установки.**
Проверьте, что файлы на месте:

```bash
ls ~/.claude/skills
```

Должно вывести `airl-cybersecurity`, `airl-hub`, `airl-pwa`, `airl-spec`, `architecture`, `design`, `security`. Если пусто — повторите шаг 3.
Если список есть, а навыков не видно — вы пропустили шаг 4, перезагрузите окно.

**Пишу `/design` в терминале, ничего не происходит.**
Навыки набираются в панели Claude справа, а не в чёрном терминале снизу.

**Ошибка `command not found: git`.**
Установите git с [git-scm.com](https://git-scm.com) и повторите шаг 3.

**Claude отвечает не на русском.**
Напишите ему: «Отвечай на русском языке».
