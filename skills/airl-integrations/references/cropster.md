# Cropster: данные обжарки

Справочник `/airl-integrations`. Cropster — программа учёта обжарки кофе
(обжарки, профили, партии зелёного зерна, контроль качества). Для обжарочного
производства это источник объектов проверки для модуля `inspection-journal`
(вопрос 2 настройки: «объекты из программы производства»). Только чтение:
в Cropster мы не пишем.

## Способы получить данные

| Способ | Задержка | Что нужно | Проверить |
|---|---|---|---|
| API Cropster | минуты | доступ к API в тарифе клиента, ключ и секрет API | **есть ли API в тарифе клиента**, адрес и версия API, авторизация, лимиты — в документации Cropster и у их поддержки |
| Выгрузка CSV/Excel по расписанию | сутки или смена | отчёт в Cropster, который сотрудник выгружает или Cropster отправляет на почту | какие отчёты умеют выгружаться автоматически и в каком составе колонок |
| Ручная выгрузка | смена | сотрудник выгружает после смены | процесс и ответственный, оповещение «нет файла» |

API — только если он уже входит в тариф клиента или клиент готов его подключить
к неделе 1. Иначе — выгрузка; переход на API — фаза 1.

## Что берём

| Объект | Поля (названия в Cropster — проверить) | Зачем |
|---|---|---|
| Обжарка (roast, batch) | ID, номер партии, дата/время начала и конца, машина, обжарщик, профиль, вес зелёного, вес обжаренного, потеря веса %, время обжарки, время развития, конечная температура | объект проверки, стабильность |
| Профиль (profile) | ID, название, продукт/SKU | связь обжарки с продуктом |
| Партия зелёного зерна (green lot) | ID, название, поставщик, происхождение | `lot` в журнале проверок |
| Измерение степени обжарки | цвет по прибору (шкала прибора клиента), время измерения | пункт чек-листа с допуском по SKU |
| Каппинг / оценки качества | сессия, оценка, дефекты | если клиент ведёт их в Cropster — читаем; иначе — в журнале AIRL |

Персональных данных нет; обжарщик — по ID пользователя, имя только в справочнике
сотрудников клиента.

## Связь с журналом проверок

Адаптер `src_inspection_objects` поверх загруженных обжарок:

| Колонка входа | Откуда |
|---|---|
| `object_id` | ID обжарки в Cropster (`cropster:<id>`) |
| `object_type` | `batch` |
| `title` | номер партии + профиль |
| `sku` | по таблице соответствия «профиль → SKU» (ведёт клиент) |
| `lot` | ID партии зелёного зерна |
| `produced_at` | время окончания обжарки |
| `produced_by` | ID обжарщика |
| `branch_id` | цех/машина, если цехов несколько |

- Таблица `int_cropster_profile_sku (profile_id, sku, active)` — у клиента
  профили называются не так, как SKU в 1С; без соответствия стабильность по продукту
  не посчитать. Профиль без SKU — отчёт «профиль без продукта», а не пропуск.
- Степень обжарки из Cropster можно предзаполнять в пункт чек-листа «цвет обжарки»
  (контролёр подтверждает) — решить с руководителем участка: предзаполнение
  экономит время, но контролёр перестаёт мерить сам.
- Загрузка по водяному знаку (время изменения обжарки, если API его даёт;
  иначе — окно «последние 3 дня» с upsert по ID). Обжарку в Cropster иногда
  правят задним числом — окно перечитки обязательно.

## Разбор выгрузки CSV

- Формат (разделитель, кодировка, формат даты, десятичный разделитель, единицы
  веса и температуры) — **зафиксировать по реальному файлу** клиента и проверять
  заголовок при каждом файле: колонки изменились — файл в карантин, оповещение,
  а не тихая загрузка мусора.
- Ключ — ID обжарки из файла; нет ID — номер партии + время начала.
- Файл переносится в архив после успешной загрузки; повторная загрузка того же
  файла ничего не меняет.

## Сверка и метрики

- Число обжарок за смену в Cropster = в журнале (`src_inspection_objects`).
- Суммарный вес зелёного за день = в Cropster (защита от потерянных строк).
- Метрики цели `cropster` в `int_health`: свежесть последней загрузки, ошибки
  разбора, профили без SKU.

## Приёмка

- [ ] обжарка в Cropster появляется в журнале проверок в пределах цикла загрузки;
- [ ] каждая обжарка связана с SKU и партией зерна или попала в отчёт;
- [ ] правка обжарки задним числом подтягивается;
- [ ] изменённый формат файла не грузится молча;
- [ ] сверка числа обжарок и веса за неделю сходится.
