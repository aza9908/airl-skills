# Сообщения: Telegram, WhatsApp, SMS

Справочник `/airl-integrations`. Типовые требования: уведомления клиентам
и пациентам (запись, статус заказа, напоминание об оплате), бот для приёма
обращений, сводка руководителю (`/airl-ai`). В курс сообщения клиентам берутся,
только если согласие утверждено юристом, а для SMS — имя отправителя уже
зарегистрировано (`scope.md`).

## Общее для всех каналов

- **Отправка — через outbox** с ключом `<канал>:<событие>:<объект>:<получатель>`
  (тот же, что `dedup_key` в `airl_notifications` модулей): повторный запуск
  не шлёт дубль.
- **Согласие и отказ**: таблица предпочтений контакта (канал, согласие, версия
  текста согласия, когда дано, когда отозвано). Перед каждой отправкой —
  проверка. Отписка («СТОП», кнопка, блокировка бота) записывается сразу
  и действует на все будущие отправки этого типа.
- **Транзакционные и рекламные** — разные основания: напоминание о записи
  и статус заказа — по договору/услуге; рассылки и акции — только с отдельным
  согласием. Границу — **проверить у юриста** по закону страны.
- **Тихие часы**: не отправлять ночью по часовому поясу получателя (настройка),
  кроме срочных служебных.
- **Особые данные** (`country.md`): в тексте только время и название организации —
  без специальности врача, диагноза, результатов.
- Номер получателя — E.164; текст — из шаблона с подстановками, не свободный текст
  из базы.

## Telegram Bot API

- Вебхук: `setWebhook` с параметром `secret_token`; Telegram присылает его
  в заголовке `X-Telegram-Bot-Api-Secret-Token` — проверка `verify_telegram_secret`
  из `scripts/webhook_verify.py`, без него — 401. Адрес — `/<id>/tg/webhook`
  (открыт без токена хаба, по карте).
- Дедупликация — по `update_id` в `int_inbox` (источник `tg`); ответ 200 сразу,
  разбор асинхронно. Telegram повторяет доставку, если не получил 200.
- Бот может писать человеку **только после того, как человек сам написал боту**
  (`/start`). Связь «ID в Telegram ↔ карточка клиента» — только после того, как
  человек поделился контактом кнопкой запроса контакта (правило карты и
  `/airl-cybersecurity`, группа 0). `callback_data` — проверять на сервере.
- Ограничения скорости (по FAQ Telegram, **проверить актуальные**): около
  30 сообщений в секунду суммарно на бота, не больше ~1 сообщения в секунду
  в один чат, около 20 в минуту в одну группу. Превышение — ответ 429
  с `retry_after`: воркер ждёт столько и повторяет (`RetryableError(retry_after=...)`).
  Массовая рассылка — темп ниже лимита, пачками.
- Ответ 403 «бот заблокирован пользователем» — не повторять и не в dead: обработчик
  отмечает контакт отписавшимся и возвращает успех с пометкой `blocked` в `response`.
- Токен бота — секрет на сервере; у разработчиков свои тестовые боты.

## WhatsApp Business

- **Только официальная платформа WhatsApp Business** (Cloud API Meta) напрямую
  или через официального провайдера (BSP). Неофициальные «шлюзы» через личный
  номер — никогда: блокировка номера, нарушение правил, утечка переписки.
- Сообщения по инициативе компании — только **предварительно одобренными
  шаблонами**; свободный текст — в пределах окна обслуживания после сообщения
  клиента (24 часа — проверить актуальные правила). Шаблоны подаются на модерацию
  заранее: сроки и цены — проверить у BSP.
- Вебхуки входящих и статусов доставки — подпись по документации платформы
  (HMAC-SHA256 тела секретом приложения — проверить), inbox, дедупликация по ID
  сообщения.
- Нужен отдельный номер для WhatsApp Business и верификация компании — время
  на неделе 0.

## SMS

| Страна | Кандидаты (уточнить в день выбора) | Что важно |
|---|---|---|
| UZ | Eskiz, Playmobile — проверить условия и API | регистрация имени отправителя и, по данным провайдеров, модерация шаблонов — от нескольких дней до недель |
| KZ | местные SMS-агрегаторы (например, Mobizon, SMSC.kz — уточнить) | регистрация имени отправителя у операторов — сроки уточнить |

- Имя отправителя (альфа-имя) регистрируется заранее; без него сообщения
  уходят с цифрового номера или не уходят вовсе — **уточнить у провайдера**.
- Статусы доставки — вебхуком или опросом; отправка без отчёта о доставке не
  считается доставленной в показателях.
- SMS платные: потолок расходов в день на цель (проверка в обработчике до отправки)
  и оповещение при приближении.
- Длина: кириллица и узбекская латиница с `oʻ gʻ` — кодировка UCS-2, сегменты
  короче (70 символов против 160) — учитывать в цене и в шаблонах.

## Выбор канала

1. Telegram — бесплатно, главный канал в UZ, но нужен `/start` от человека.
2. WhatsApp — если клиенты там, а не в Telegram; шаблоны и плата за сообщения.
3. SMS — запасной канал для критичных напоминаний тем, у кого нет мессенджера.
Порядок попыток (Telegram → SMS через N минут без доставки) — настройка,
каждая попытка — своя запись outbox со своим ключом.

## Приёмка

- [ ] вебхук без секрета — 401; повтор `update_id` не обрабатывается дважды;
- [ ] сообщение не уходит без согласия и после отписки;
- [ ] повторный запуск рассылки не шлёт дубль;
- [ ] при 429 воркер ждёт `retry_after`, сообщения не теряются;
- [ ] тексты без особых данных; тихие часы соблюдаются;
- [ ] потолок расходов на SMS срабатывает.
