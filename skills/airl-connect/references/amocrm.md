# amoCRM (Kommo): что закрывает и как забирать данные

Справочник для `/airl-connect`. amoCRM — система про продажи: воронка, сделки,
мессенджеры, автоматизация продаж. Внутренние задачи компании, согласования,
базу знаний и HR она не закрывает — для них нужен Bitrix24 или модули AIRL.
Международная версия называется Kommo. Возможности и тарифы — проверить на сайте
в день выбора.

## Данные в хаб: API v4

**Доступ.** Приватная интеграция в настройках аккаунта с **долгосрочным токеном**
(путь в меню — проверить в аккаунте клиента). Токен — секрет: переменная
`AMOCRM_TOKEN` в `.env` на сервере. Адрес аккаунта — `AMOCRM_BASE_URL`, например
`https://<поддомен>.amocrm.ru` или `https://<поддомен>.kommo.com`.

**Списки** — `GET /api/v4/<сущность>?limit=250&page=N`, заголовок
`Authorization: Bearer <токен>`. Ответ: записи в `_embedded.<сущность>`, следующая
страница — в `_links.next`; пустой результат — ответ `204` без тела. Изменённые
после даты — `filter[updated_at][from]=<время в секундах Unix>`.

| Сущность в `extract.py` | Путь | Ключ | Поле изменения |
|---|---|---|---|
| `leads` (сделки) | `/api/v4/leads` | `id` | `updated_at` |
| `contacts` | `/api/v4/contacts` | `id` | `updated_at` |
| `companies` | `/api/v4/companies` | `id` | `updated_at` |
| `tasks` | `/api/v4/tasks` | `id` | `updated_at` |
| `events` (история изменений) | `/api/v4/events` | `id` | `created_at` |
| `pipelines` (воронки и этапы) | `/api/v4/leads/pipelines` | `id` | — |
| `users` | `/api/v4/users` | `id` | — |

**Лимиты.** Порядка 7 запросов в секунду на аккаунт, при превышении — ответ `429`
(точные значения — проверить в документации). `extract.py` держит паузу и повторяет
с нарастающей паузой.

**Время** в amoCRM — секунды Unix (`updated_at`, `closed_at`). В представлениях
переводи `to_timestamp(...)`.

## Представление `core` (пример)

```sql
CREATE OR REPLACE VIEW core.crm_deals AS
SELECT
    'amocrm:' || r.source_id                                AS deal_id,
    r.payload->>'name'                                      AS title,
    (r.payload->>'price')::numeric(18,2)                    AS amount,
    r.payload->>'pipeline_id'                               AS pipeline_id,
    r.payload->>'status_id'                                 AS stage_id,
    r.payload->>'responsible_user_id'                       AS manager_source_id,
    to_timestamp((r.payload->>'created_at')::bigint)        AS created_at,
    to_timestamp(NULLIF(r.payload->>'closed_at', '')::bigint) AS close_date
FROM raw_amocrm.records r
WHERE r.entity = 'leads' AND NOT r.is_deleted;
```

Этапы 142 и 143 в amoCRM — служебные «успешно реализовано» и «закрыто и не
реализовано» во всех воронках; конверсия считается по ним (проверить в аккаунте).
